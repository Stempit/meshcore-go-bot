# eightball — magic 8-ball

Package `eightball` registers the `.8ball` command: answers a yes/no question with a
random Magic 8-Ball phrase (the 20 classic answers, translated to Russian). Like the
toy, the question text itself is ignored.

## Command surface

```
.8ball <вопрос>   – random да/нет/может-быть answer, prefixed 🎱
```

Empty question → `задай вопрос: .8ball <вопрос>`.

## Configuration

None.
