# meshbot 📻🤖

**Ваша автономная mesh-рация, которая отвечает.**

*[🇬🇧 Read in English](README.md)*

meshbot превращает LoRa-устройство [MeshCore](https://meshcore.io) в полноценного
чат-бота, который живёт **прямо в mesh-сети** — без сотовой связи, без Wi-Fi, без
интернета со стороны радио. Пингуйте его, задавайте вопросы, играйте с соседями по эфиру,
читайте новости, узнавайте погоду или пересылайте сообщения в Telegram — всё это по
дальнобойному радио и из одного крохотного бинарника на Go.

---

## Почему он вам нужен

- 📡 **Работает там, где не работает ничего.** Чистый LoRa mesh. Автономные лагеря, зоны
  без покрытия, ЧС, полевые задачи — если два узла MeshCore слышат друг друга, meshbot
  уже на связи.
- 🧠 **ИИ в mesh-сети.** `.llm` и `.claw` приносят LLM / ИИ-агента в сеть, где интернета
  нет и в помине (наружу ходит хост бота, а эфир остаётся чисто радийным).
- 🎮 **Это правда весело.** Броски кубиков на выбывание, виселица, «угадай число», гонки
  по составлению слов и живые голосования — с таблицами лидеров за 30 дней. Ваш канал
  превращается в игровую комнату.
- 🌉 **Мост во внешний мир.** Двусторонний Telegram, публикация по MQTT в анализатор
  [Let's Mesh](https://letsmesh.net), заголовки RSS и оперативные оповещения о БПЛА и ЧС
  прямо в канал.
- 🛰️ **Рассчитан на плохое радио.** Ответы в канал передаются несколько раз с
  *адаптивной ранней остановкой* (бот слушает, как сеть ретранслирует его же пакет, и
  замолкает раньше) — сообщения реально доходят, чего обычные каналы MeshCore никогда не
  подтверждают.
- 🌍 **Двуязычный.** Полный интерфейс на русском 🇷🇺 и английском 🇬🇧, переключается одним
  ключом в конфиге.
- 🧩 **Бесконечно расширяемый.** Каждая команда — самоподключающийся плагин: добавьте
  папку, добавьте одну строчку импорта — готово. Никакого центрального switch.

## Что он умеет

Общайтесь по радио простыми `.командами`:

| | Команда | Что делает |
|---|---|---|
| 🏓 | `.ping` / `пинг` | Ты на связи? (с характером) |
| 🛰️ | `.trace` | Число хопов + реальное расстояние до вас |
| 📜 | `.last [n]` | Свежая история канала |
| 📰 | `.news [лента]` | Заголовки RSS |
| 🧠 | `.llm <вопрос>` | Спросить LLM |
| 🐾 | `.claw <вопрос>` / `@Бот` | Спросить ИИ-агента picoclaw |
| ☀️ | `.w [город]` | Погода сейчас / на завтра |
| 🗺️ | `.path A to B` | Лучший маршрут между репитерами |
| 🏆 | `.top` · `.stat` | Активность канала и трафик за 24ч |
| 🎱 | `.8ball <вопрос>` | Магический шар |
| 🎟️ | `.ticket` | Ваш личный стабильный позывной |
| 💬 | `.2ch` | Маленький форум/BBS прямо в mesh |
| 🎲 | `.dice` `.num` `.hang` `.words` `.vote` | Игры и опросы с таблицами лидеров |
| ❓ | `.help` | Узнать про всё |

А в фоне бот тихо делает своё дело: приветствует новые узлы, подсказывает старым узлам
перейти на современную маршрутизацию, пересылает Telegram ⇄ mesh, публикует данные в
MQTT-анализаторы и рассылает оповещения об опасностях.

## Плюсы и минусы

**Плюсы**
- ✅ Работает автономно в LoRa mesh — интернет для работы по радио не нужен
- ✅ Огромный набор возможностей из коробки: инфо, ИИ, игры, мосты, оповещения
- ✅ Настоящая надёжность доставки в ненадёжной среде без подтверждений
- ✅ Один статический бинарник на Go; подключение по **Bluetooth LE или USB-serial**
- ✅ Двуязычный (en/ru); ответы подогнаны под жёсткий лимит байт в mesh
- ✅ Чистая плагинная архитектура — легко расширять, каждый пакет документирован

**Минусы** *(мы честны)*
- ⚠️ Нужно совместимое с MeshCore LoRa-устройство
- ⚠️ Функции ИИ / погоды / Telegram требуют интернета **на хосте бота**
- ⚠️ Язык общий для всего бота (не по пользователям); смена = правка + перезапуск
- ⚠️ Конфиг — один YAML, читается при старте; чтобы применить, нужен перезапуск
- ⚠️ Часть игр идёт со словарями только на русском
- ⚠️ Ответы намеренно краткие (лимит 140 байт); автотестов пока нет

## Быстрый старт

```bash
# из корня репозитория:
cp config.example.yaml config.yaml   # затем впишите устройство и секреты
go build ./cmd/bot
./bot                                # читает config.yaml в текущей папке
```

Подключите устройство MeshCore по BLE (или укажите serial-порт), зайдите в канал и
отправьте `.help`.
